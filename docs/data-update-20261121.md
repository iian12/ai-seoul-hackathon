# 데이터 집계·원천 보완 (2026-11-21)

기존 예산·전세/월세·지역·반경·중요도 입력을 유지한다. 주택유형·면적·층·연식 선택이나 통근시간 조회 기능은 제공하지 않는다.

## 집계

- 전체 전월세 원천 2,701,942행을 검사한다. 전체 유효 월세 1,629,939행·전세 1,071,773행과 제외 사유를 보존한다.
- 공개 주거비 집계는 원천의 마지막 계약일 기준 최근 24개월이다. 현재 기간은 **2024-11-13~2026-11-13**, 월세 **1,046,062행**, 전세 **629,552행**이다. 현재 날짜 기준의 실시간 시세라는 뜻이 아니다.
- 모든 주택유형·면적을 포함한다. 숨겨진 40㎡ 제한이나 유형별 제외는 없다.
- 보증금·월세의 공동 분포를 유지한다. 최소 10건·두 예산 동시 충족·중앙값·동점 규칙은 기존 규칙을 사용한다.
- 면적·유형·정확한 계약일·층·건축연도·신규/갱신 값은 비공개 SQLite `lease_detail`에 보존한다. 누락된 층·연도는 `null`이며 추정하지 않는다. 상세 거래를 브라우저로 보내지 않는다.
- 원천 수집일과 집계 생성일을 구분한다. 기존 캐시를 다시 집계한 날을 새 수집일로 표시하지 않는다.
- 공개 JSON과 gzip 사본을 생성하며 기존 화면이 압축본을 우선 읽는다.

운영시간은 공시 시간표이며 실시간 영업·진료·응급 수용 상태가 아니다. 야간 약국은 시작·종료 시간을 함께 검사하고 자정을 넘기는 시간을 처리한다. 기관 ID를 기준으로 중복을 제거한다.

CCTV 수집이 승인되면 방범·범죄예방·다목적 용도를 확인한 지점만 사용한다. 교통단속 전용·용도 미확인 자료를 방범 CCTV로 간주하지 않는다. 기존 CCTV 지점 수에 새 목록을 중복 합산하지 않으며, 카메라 대수가 없으면 임의로 1대를 만들지 않는다. 비상벨 투영좌표는 검증 후 WGS84로 변환한다.

전량 수집 중 전체 건수가 달라지거나 페이지가 누락·반복되면 해당 원천은 완료로 처리하지 않는다. 미승인·키 누락·수집 실패를 실제 0건으로 바꾸지 않는다. 원본과 상세 오류 상태는 Git 제외된 `data/enrichment/`에 보관한다. 공개 자료에는 키·요청 URL·오류 원문을 넣지 않는다.

## 실행

서버 키는 Git 제외된 `.env.server.local`에 둔다. 추가 변수는 `.env.server.example`을 참고한다. 공공데이터포털 인증키가 같더라도 새 서비스별 활용승인은 각각 필요하다.

```sh
# 기존 원본으로 집계 재생성 + 보완 API 수집 + 실제 데이터 검증
npm run data:rebuild

# 원천 전체를 새로 수집. 기존 캐시는 백업 이름으로 보존
npm run data:sync -- --refresh

# 위치 점검 파일이 처음부터 없는 환경
npm run data:point

npm test
npm run enrichment:test
npm run data:check
npm run build
npm run check:secrets
```

전월세 수집은 서울 시간 기준 최근 3개 접수연도를 계산한다. 특정 연도 배열이나 2,701,942라는 과거 총 건수를 다음 수집의 전제로 고정하지 않는다. 수집 중에는 페이지별 전체 건수·행 수를 대조한다.

확인한 검증: 자동 테스트 34개, 서울 25개 구·467개 법정동의 집계 건수, 전세·월세 TOP 3의 최근 기간 표본·예산 적합 건수·중앙값과 SQLite 원자료 일치, 도보 경로 452개, 프로덕션 빌드·비밀키 검사. 원격 Supabase 적용·외부 배포는 수행하지 않았다.
