# 학교·직장 기준 위치와 반경

- 기준점 한 곳을 선택하고 0.5~20km(0.5km 단위) 반경을 지정합니다. 이름은 직접 바꿀 수 있습니다.
- 검색 원천은 기존 도보 경로에 사용한 OpenStreetMap의 BBBike 서울 PBF 추출본입니다. 배포 파일 갱신은 2026-11-15 01:19 KST이며, 개별 장소의 조사일을 뜻하지 않습니다. 네이버·카카오 검색이나 신규 공공 API를 연결한 기능이 아닙니다.
- `npm run places:build`는 `data/walking/seoul.osm.pbf`와 메타정보를 읽어 `public/data/seoul-places.json`을 만듭니다. Python osmium 환경은 도보 경로 구축과 동일합니다. 학교·회사·건물·일부 시설 이름, 태그에 수록된 도로명주소 총 214,230개를 추출했습니다. 추출 영역에 서울 인접 지역도 포함되지만 검색 결과와 기준점은 기존 서울 경계 안으로 제한합니다. ODbL 출처를 UI에 표시합니다.
- 검색은 로컬 데이터에서 이루어집니다. 검색어와 선택 좌표를 지오코딩 서비스로 전송하거나 사용자 설정으로 영구 저장하지 않습니다. 지도 배경 타일은 기존 OpenStreetMap 서버를 이용합니다. 주소·기업 전체를 수록한 공식 명부가 아니며 OSM 태그 누락·표기 오류·중복이 있을 수 있습니다. 검색되지 않으면 지도를 확대해 직접 지정할 수 있습니다.
- 노드 좌표 또는 건물·캠퍼스 도형의 외접 사각형 중심을 검색 결과 위치로 사용합니다. 출입구 좌표를 보장하지 않으며 지도에서 실제 위치를 확인할 수 있습니다. 지도에서 지정할 때는 원형/경계 등 오버레이가 아닌 지도 배경을 클릭합니다.
- 반경은 Haversine 직선거리입니다. **동네 대표점**이 원 안에 있을 때 포함하며 동 전체나 모든 매물이 반경 안에 있다는 뜻은 아닙니다. 추천 후보를 먼저 반경으로 거른 다음 기존 예산 동시 충족·최소 10건·가중치로 TOP3를 선정합니다. 점수 자체를 재정규화하지 않습니다.
- 위치/반경 변경은 이전 추천을 지우고 지도와 지역 목록을 즉시 갱신합니다. 예산과 중요도는 유지하며 ‘내 동네 찾아보기’로 다시 계산합니다. 기준 위치 해제 시 서울 전체 후보로 돌아갑니다. 빈 결과에서는 반경·예산 조정을 안내합니다.
- 이 반경은 역까지 보행 경로와 별개입니다. 역 도보 모델은 유지하며 기준 위치까지의 출근·통학 보행 경로/시간은 계산하지 않습니다.
- 검증: 정확한 반경 경계 포함, 서울 밖 좌표/비정상 반경 거절, 반경 적용 후 순위, 기존 예산·점수 보존, 0원 예산, 해제 동등성, 한글 공백/주소 검색, 서울 밖 검색 결과 제외를 단위 테스트합니다.
