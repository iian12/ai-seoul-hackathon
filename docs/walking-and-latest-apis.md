# 역 도보 접근성과 최신 데이터 API 조사

확인일: **2026-11-16, Asia/Seoul**. 사용자 최종 지시에 따라 **예산 입력·예산 필터·주거비 점수는 유지**했습니다.

## 적용한 도보 계산

- 모델 버전: `seoul-walking-1.0`.
- 키가 없는 상태에서 [BBBike 서울 OSM 추출본](https://download.bbbike.org/osm/bbbike/Seoul/)을 받아 로컬 보행 그래프를 만들었습니다. 추출본 HTTP 갱신 시각은 **2026-11-15 01:19:11 KST**입니다(원본 헤더: `Sat, 14 Nov 2026 16:19:11 GMT`). 이 시각은 배포 파일의 갱신 시각이지 모든 도로의 개별 조사일이 아닙니다.
- 그래프: 약 108만 노드·122만 도로 구간. 서울 안의 지하철 출입구 1,818개 중 1,777개를 그래프에 직접 연결하거나 20m 내 인근 보행로에 보정했습니다. 직접 연결된 출입구는 218개입니다.
- 보행 금지·사유지·미해결 조건부 접근·고속화도로 등을 제외했습니다. 보행 방향 제한은 적용하고 자동차 일방통행을 보행 일방통행으로 간주하지 않습니다.
- 실제 도로 구간의 길이로 Dijkstra 최단거리를 계산합니다. 직선거리에 배수를 곱한 값이 아닙니다. 거리상 가까운 몇 개 역으로 후보를 고정하지 않고 연결 확인된 전체 출입구를 대상으로 탐색합니다.
- 출발점은 기존 법정동 대표점의 100m 안에서 가장 가까운 보행로로 보정합니다. 도착점 보정은 20m 이내입니다. 두 보정 구간은 확인된 보행 연결이 아니므로 **도보 거리·시간에 합산하지 않고 화면에 별도로 표시**합니다. 따라서 실제 집 현관에서 역 개찰구까지의 도보 시간은 아닙니다.
- 시간은 일반 길 4.5km/h·계단 0.8m/s를 가정한 추정치입니다. 최단거리 경로의 추정 시간이며, 최단시간 보장·신호 대기·실시간 통제·출입구 운영시간·휠체어 접근성은 검증하지 않았습니다.
- **452개 지역 경로 확인**, 9개는 100m 내 보행로 미확인, 6개는 연결된 출입구 경로 미확인입니다. 15개는 교통 점수를 결측으로 두어 추천에서 제외하며 직선거리 대체를 하지 않습니다.
- 교통 점수는 **역 도보 경로 60% + 버스 정류소 직선 접근성 40%**입니다. 안전·의료 거리 지표까지 도보 기준으로 바꾼 것은 아닙니다.
- 예산 동시 충족·최소 표본 10건·주거비 계산·가중치 프리셋은 기존 기능을 유지합니다.

원천과 로컬 경로 캐시는 `data/walking/`에 있습니다. `public/data/seoul-snapshot.json`에는 경로 선·거리·시간·보정거리·출처와 계산 가정이 들어 있습니다. 경로 선 길이의 합이 게시한 도보 거리와 1m 이내로 일치하는지 전체 452개를 검사합니다.

재생성:

```sh
python3 -m venv data/walking/venv
data/walking/venv/bin/python -m pip install -r scripts/requirements-walking.txt
npm run walking:download
npm run walking:build
npm run walking:apply
npm run walking:test
npm run data:check
```

`walking:download -- --refresh`는 추출본을 다시 받습니다. 일반 실행은 저장한 파일을 재사용합니다. `data:build`도 경로 캐시가 있으면 같은 대표점인지 검증한 뒤 도보 모델을 유지합니다. 대표점이 달라지면 기존 경로를 억지로 붙이지 않고 중단합니다. OSM과 BBBike 출처 및 ODbL 이용 조건을 표시합니다.

## 안전시설: 신규 CCTV API가 있음

[행정안전부 CCTV정보 조회서비스](https://www.data.go.kr/data/15155042/openapi.do)는 설치 위치·용도·위경도·카메라 수 등을 제공하는 REST API입니다. 공식 명세는 일간 갱신, 조회일 2일 전 기준의 현행화, `/info` 및 `/history`, 한 페이지 최대 100건을 안내합니다.

- 기본 경로: `https://apis.data.go.kr/1741000/cctv_info`.
- 현재 키로 `/info`를 5건 요청했으나 **HTTP 403 / 인증 코드 30 (`SERVICE_KEY_IS_NOT_REGISTERED_ERROR`)** 응답이었습니다. 발급 목록의 다른 API가 승인됐다는 사실은 이 신규 서비스 권한을 보장하지 않습니다.
- 서비스별 활용신청·승인 확인이 필요합니다. 현재 행 단위 응답이나 서울 데이터의 실제 기준일은 검증하지 못했으므로, 새 CCTV 자료를 반영했다고 표시하지 않습니다.
- 기존 [서울 안심이 CCTV 연계 26종은 2026-03-18 종료 공지](https://data.seoul.go.kr/together/notice/datasetNoticeView.do?bbsCd=10008&ditcCd=&pageIndex=1&seq=196ab1d282b61858550f68a971f922b9)가 있어 기본 원천으로 다시 의존하지 않습니다.

이 CCTV 서비스는 안심벨·보안등 전체 목록의 대체물이 아닙니다. [서초구 보안등 현황](https://www.data.go.kr/data/15128039/fileData.do)처럼 구별 위치 자료도 있으나, 포털 수정일 2026-02-03과 파일명 기준일 2024-05-13이 달라 실제 행의 기준일 확인이 필요합니다. 새 공사 계획·행정예고를 설치 완료 좌표로 취급하지 않습니다.

## 안심귀갓길: 현재 통합 API의 실제 갱신은 오래됨

[경로 OA-21695](https://data.seoul.go.kr/dataList/OA-21695/S/1/datasetView.do?tab=A), [안전시설물 OA-21696](https://data.seoul.go.kr/dataList/OA-21696/S/1/datasetView.do), [서비스 OA-21697](https://data.seoul.go.kr/dataList/OA-21697/S/1/datasetView.do)를 구분했습니다.

- 안전시설물·서비스의 공식 페이지는 **데이터 갱신일 2023-04-21**과 **메타정보 수정일 2026-11-11**을 따로 표시합니다. 2026년 수정 표시를 2026년 현장 데이터로 해석할 수 없습니다.
- 2026-11-16 현재 시점에 인증 API 3종을 전량 재조회해 원천 건수와 `REFDATE`/`REF_DATE`의 최솟값·최댓값을 확인했습니다. 결과는 [검증 기록](latest-api-checks.json)에 저장했습니다.
- 이번 조사에서는 2025~2026년 현장을 반영한 **서울 전역 통합 안심귀갓길 API**를 확인하지 못했습니다. 이는 그런 API가 존재하지 않는다는 단정은 아닙니다.
- [도봉구 공식 안내](https://www.dobong.go.kr/Contents.asp?code=10010344)는 2026-08-07 수정 및 11개 노선을 안내합니다. 최신 구별 안내는 보완 확인에 유용하지만, 좌표·선형·설치일을 갖춘 서울 전체 API와 같은 데이터가 아닙니다.

현재 안전시설 점수는 기존 관측 목록을 사용하며 오래된 기준일 경고를 유지합니다. 조사만 끝난 신규 API나 구청 안내를 실제 연동 데이터로 혼합하지 않았습니다.

## 별도 키가 있는 보행 API

[TMAP 보행자 경로 API](https://tmap-skopenapi.readme.io/reference/%EB%B3%B4%ED%96%89%EC%9E%90-%EA%B2%BD%EB%A1%9C%EC%95%88%EB%82%B4)는 별도 앱 키가 필요합니다. 사용자가 키 없는 대안을 선택해 이번에는 이용하지 않았습니다. 공개 Overpass 서버의 요청 거절·연결 문제로 도로 추출본을 택했으며, 공개 Valhalla 보행 경로도 서울 한 경로에서 응답을 확인했지만 운영 API로 의존하거나 대량 호출하지 않았습니다.
